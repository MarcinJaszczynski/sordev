# 03. UI Design System (Filament 4 & Tailwind CSS)

## 1. Paleta Barw i Kolory Statusów
* **Primary**: Amber / Indigo (akcenty biznesowe i przyciski akcji głównej).
* **Draft / Szkic**: Slate / Gray (`badge gray`).
* **Ofertowana / W trakcie**: Info Blue (`badge info`).
* **Potwierdzona / Zrealizowana**: Success Green (`badge success`).
* **Anulowana / Błąd KSeF**: Danger Red (`badge danger`).

## 2. Typografia i Formularze
* Inter lub systemowa sans-serif dla wysokiej czytelności tabel.
* Pola numeryczne walutowe zawsze wyrównane do prawej strony z automatycznym formatowaniem separatorów tysięcy (`12 450,00 PLN`).
