# UI i UX panelu

## Stack UI

- Filament 3 (tabele, formularze, akcje, modale)
- Blade + Tailwind (custom widoki, front)
- Alpine.js (interakcje Livewire)
- Style admin: `resources/views/filament/components/admin-readability-styles.blade.php`

## Wzorzec list (Filament Table)

Każda większa lista powinna mieć tam gdzie sensowne:

- wyszukiwanie (`->searchable()`)
- filtry (`->filters()`)
- sortowanie
- akcje wiersza i bulk
- kolumny toggleable na mobile (`visibleFrom`, `toggleable`)

## Estetyka (cel)

Inspiracja: Stripe / Linear — czytelność, spacing, subtelne obramowania, profesjonalny dashboard.

**Pełny system projektowy:** [DESIGN_SYSTEM.md](../DESIGN_SYSTEM.md) — kolory, typografia, ikony grup menu, komponenty, responsywność.

## Responsywność

- Tabele: poziomy scroll na `< md`
- Przyciski dotykowe min. ~44px w panelu pilota
- Test: `docs/MANUAL_TESTS.md` sekcja responsywności

## Formatowanie pieniędzy

Zawsze `MoneyFormatter::format($kwota, $waluta)` — nie `number_format` + hardcoded „PLN”.
