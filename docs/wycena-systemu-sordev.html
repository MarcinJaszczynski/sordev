≈ 8 500–9 000 godzin · ≈ 1,9–2,0 mln zł
Przy stawce blended 220 zł/h. Obejmuje development, prace koncepcyjne, spotkania, zmiany koncepcji, poprawki UAT, wdrożenie i koordynację.

1. Podsumowanie wykonawcze

SORDEV to nie klasyczny panel CRUD, lecz ERP operatora imprez: wyceny i szablony, umowy z aneksami, rozliczenia, harmonogramy płatności, import bankowy, PayU, TFG, portale klienta i pilota, rezerwacje/hotele/transport, pipeline sprzedażowy oraz raporty.

Skala systemu (orientacyjnie)

  • ~112 modeli Eloquent
  • ~170 serwisów domenowych
  • ~45 resource’ów Filament
  • 3 panele: admin / klient / pilot
  • ~265 migracji, ~200 testów
  • rząd ~200k+ LOC (app + DB + testy + views)

Trzy warstwy wyceny

  • A. Sam development (kod)
  • B. Narzut pozakodowy (koncepcja, spotkania, pivots, UAT, PM)
  • C. Wartość całościowa przedsięwzięcia

W projektach tej klasy prace pozakodowe często dorównują nakładowi implementacji.

2. Założenia wyceny

  • Stawka bazowa (blended): 220 zł/h (senior + mid, Filament + domena).
  • Porównawczo: freelance senior 180 zł/h · software house 250–280 zł/h.
  • Zakres: koszt odtworzenia kodu i logiki oraz typowych prac projektowych.
  • Poza zakresem: hosting, utrzymanie 24/7, licencje SaaS, marketing produktu.
  • Waluta: PLN; EUR orientacyjnie przy kursie ~4,3 zł.
Uwaga metodologiczna: to szacunek ekspercki na podstawie skali i złożoności istniejącego systemu, nie audyt księgowy ani wycena spółki. Widełki wynikają z niepewności odkrywania domeny i historycznej zmienności koncepcji.

5. Prace koncepcyjne, spotkania, zmiany i poprawki

Sam kod zwykle stanowi tylko część całkowitego nakładu. W ERP finansowo-operacyjnym typowy narzut pozakodowy wynosi ok. 70–120% developmentu.

Kategoria Co wchodzi % od dev Godziny*
Prace koncepcyjne / discovery Mapowanie procesów, model domeny, decyzje o statusach/płatnościach/umowach, UX flow 15–25% 700–1 150
Spotkania / synchronizacja Warsztaty z biznesem, statusy, ustalenia z księgowością/operacjami, review decyzji 8–15% 370–690
Zmiany koncepcji / pivots Przeróbki po feedbacku, zmiana modelu rozliczeń, redesign flow umów 20–35% 920–1 610
Poprawki po UAT / stabilizacja Bugi domenowe, edge case’y, dopięcie po realnych imprezach 12–20% 550–920
Dokumentacja / wdrożenie / szkolenie Instrukcje, onboarding, migracja legacy, go-live 8–12% 370–550
PM / koordynacja Planowanie, priorytety, ryzyko, komunikacja 8–12% 370–550
Suma narzutu pozakodowego ~70–120% ~3 300–5 500

* Przy bazie developmentu ~4 600 h.

Reguła praktyczna: 1 h dobrego kodu domenowego ≈ 0,8–1,2 h pracy koncepcyjnej, uzgodnień i poprawek. Dlatego baza ~4,5k h kodu przekłada się na całość ~8,5–9k h.

8. Wartość zastąpienia (IP / sprzedaż gotowego produktu)

Przy wycenie IP lub sprzedaży gotowego produktu często stosuje się mnożnik 1,2–1,5× względem kosztu odtworzenia (ryzyko, time-to-market, know-how domenowe).

  • Baza odtworzenia: ~1,9–2,0 mln zł
  • Wartość zastąpienia z mnożnikiem: ~2,3–3,0 mln zł
  • Przy stawce software house (250–280 zł/h) całość projektowa: ~2,1–2,5 mln zł przed mnożnikiem IP

9. Dlaczego narzut pozakodowy jest wysoki

  1. Finanse i umowy — decyzje biznesowe dojrzewają dopiero przy realnych rozliczeniach.
  2. Trzy panele (admin / klient / pilot) — różni stakeholderzy i różne koncepcje UX.
  3. TFG + bank + PayU — integracje generują poprawki także po go-live.
  4. Legacy / migracje — zwykle 1–2 duże zmiany koncepcji danych w trakcie projektu.
  5. Spotkania operacyjno-księgowe — bywają droższe czasowo niż sam CRUD UI.
