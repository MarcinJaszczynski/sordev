## Cel

Zaimportować wyciąg / plik przelewów i przypisać wpłaty do właściwych imprez i uczestników bez ręcznego przepisywania każdej kwoty.

## Kroki

1. Wejdź w **Finanse → Import wpłat bankowych** (lub odpowiedni link z pulpitu finansowego).
2. Wgraj plik CSV / wyciąg w oczekiwanym formacie.
3. Przejrzyj podgląd linii — kwoty, tytuły, daty.
4. Dopasuj linie do uczestników / imprez (propozycje systemu + ręczna korekta).
5. Zatwierdź import (zastosuj) — powstają wpłaty w rejestrze.
6. Wejdź w imprezę → **Finanse → Wpłaty** i potwierdź salda.

## Wynik

Wpłaty z konta bankowego są w systemie i zmniejszają należności uczestników.

## Typowe błędy

- Zły format pliku — sprawdź podgląd przed zatwierdzeniem.
- Dopasowanie po samym nazwisku przy kilku imprezach — weryfikuj kod imprezy w tytule przelewu.
- Ponowny import tego samego pliku bez kontroli duplikatów.
